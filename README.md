# 贪吃蛇游戏

## 项目简介
这是一个经典的贪吃蛇游戏实现，支持单人和双人对战模式。

## 功能特性

### 单人模式
- 使用 WASD 或方向键控制蛇的移动
- 吃到食物（F）增加分数和长度
- 撞墙或撞到自己游戏结束

### 双人对战模式
- **玩家1**：使用 WASD 控制，蛇身为绿色
- **玩家2**：使用方向键控制，蛇身为蓝色
- 碰撞到对方蛇身或边界则游戏结束
- 实时分数面板显示两个玩家的当前分数和最高分

## 游戏控制

### 玩家控制
- **玩家1**：W（上）、A（左）、S（下）、D（右）
- **玩家2**：↑（上）、←（左）、↓（下）、→（右）

### 游戏控制
- **ENTER**：开始游戏
- **SPACE**：暂停/继续游戏
- **R**：重新开始游戏
- **ESC**：退出游戏

## 项目结构
```
snake-game/
├── snake.cpp              # 单人模式原始代码（未修改）
├── src/
│   ├── main.cpp          # 程序入口
│   └── features/
│       └── MultiplayerGame.cpp  # 双人对战模式实现
├── include/
```

## 编译和运行

### 编译
```bash
g++ -o snake-game src/main.cpp src/features/MultiplayerGame.cpp -I include
```

### 运行
```bash
./snake-game
```

## 技术特点
- 使用面向对象编程（OOP）设计
- 实现了完整的碰撞检测系统
- 支持彩色终端显示
- 实时分数统计和最高分记录
- 游戏状态管理（菜单、游戏中、暂停、结束）

## 碰撞检测
游戏实现了三种碰撞检测：
1. **边界碰撞**：蛇头碰到游戏边界
2. **自撞**：蛇头碰到自己的身体
3. **互撞**：蛇头碰到对方的身体

## 开发说明
- 多人模式代码严格遵循约束要求，放在 `src/features/` 目录下
- 使用大驼峰命名法命名组件文件（MultiplayerGame.cpp）
- 头文件放在 `include/` 目录下，与组件名一致
- 未修改原始 `snake.cpp` 文件，保持其核心逻辑不变
